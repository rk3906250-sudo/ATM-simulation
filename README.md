# ATM Simulation

## Description

This is a simple ATM Simulation project developed using C++ and Object-Oriented Programming concepts.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Check insufficient balance
- Display transaction messages

## Technologies Used

- C++
- Object-Oriented Programming (OOP)

## How to Run

1. Open `main.cpp` in VS Code.
2. Compile the program using a C++ compiler.
3. Run the generated executable.
4. Follow the instructions displayed in the terminal.

## Project Purpose

This project was created to practice C++ programming and Object-Oriented Programming concepts such as classes, objects, encapsulation, and member functions.
